## Elevator Pitch

“Hey everyone, my name is Shane, and this is my Alchemy University final project: an on‑chain achievement badge system built on an EVM chain.

The idea behind this project is simple. In web3, most achievements still live off‑chain — things like finishing a course, contributing to a project, or participating in an event. They usually end up as Discord roles, screenshots, or centralized badges that aren’t verifiable and aren’t truly owned by the user. There’s no trustless way to prove what you’ve accomplished.

My solution is a smart‑contract‑powered badge system that lets users mint verifiable achievements directly on‑chain. Each badge is an ERC‑1155 token with metadata that describes what the badge represents and when it was earned. Badges can be claimable through the front‑end, or through a signature‑based flow using EIP‑712, which allows for secure, permissioned claims. I also added optional soulbound logic so badges can’t be transferred, making them true proof‑of‑achievement tokens.

In the demo, I’ll show how a user connects their wallet, claims a badge, and instantly sees it appear on‑chain and in the UI. Everything is deployed to a testnet, and the system is designed to be modular so new badges, categories, or rarity tiers can be added without redeploying the entire contract.

The goal of this project is to create a simple, interactive, and verifiable way to showcase accomplishments — something that can be used for education, events, communities, or even gamified ecosystems. It’s a foundation that can grow into a full progression system or integrate with other dApps.”
